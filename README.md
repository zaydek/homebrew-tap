# Zaydek Homebrew Tap

Homebrew tap for Zaydek-distributed tools.

## adderall

Install on Apple Silicon macOS Ventura or newer:

```sh
brew install zaydek/tap/adderall
adderall install
adderall doctor
add 5s
```

`adderall install` is a one-time per-Mac setup step. It creates the scoped
sudoers entry required for `pmset disablesleep`.
